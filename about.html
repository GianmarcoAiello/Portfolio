02Principles
Evidence
Every AI answer carries its evidence. If a claim can't be traced to a source, it's not a result — it's a draft.
Process first
Exception inventory and co-design with domain experts before development. A pilot without trust metrics is a demo, not a project.
Code decides
The model proposes; deterministic code verifies and computes the final verdict. The model never sets the status.
Configuration
Rules belong in versioned data, not in code. Domain experts change a rule without a release; new domains are configuration.
